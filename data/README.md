# Данные приложения

- `Судаков Егор Алексеевич_my_forecast.csv` — собственный итоговый прогноз из ML-блока,
  скопирован без изменения из `final`. 155 строк, 30 столбцов, 5 маршрутов из Москвы,
  даты с 1 июня по 1 июля 2026 года включительно.
- `routes.csv` — исходный справочник организаторов, использованный при проверке ML.
  Источник: https://gist.github.com/Murkat-git/3ddc868889d3e0d37542d786c8b1aa74/raw/a934b1220da2b20d7f3eb397a7459fe78ea168ef/routes.csv

В `routes.csv` находятся названия маршрутов, базовые цены и чувствительность спроса.
Все цены здесь в рублях. `seats` в прогнозе — вместимость, а не остаток свободных мест.

`X_base_demand` — квантиль спроса при базовой цене. Именно эти поля нужны
для пересчёта спроса при цене, введённой пользователем.
`X_price` — оптимальная цена из ML-блока; `X_price_demand` — спрос при этой цене.
При расчёте продаж вместимость учитывается отдельно: `min(seats, max(0, спрос))`.
Квантили 0.1–0.9 описывают одно распределение, а не девять равновероятных исходов.
