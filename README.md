# Решись Авиа

Приложение для блока разработки олимпиады «Решись».
Стек: React, TypeScript, Vite, Node.js, Express, SQLite, Chart.js.

Готовы прогноз, график спроса, регистрация и вход.
План следующих этапов описан в [ARCHITECTURE.md](ARCHITECTURE.md).

## Запуск

Рекомендуется Node.js 24 из `.nvmrc`. Для встроенного SQLite нужен Node.js 22.13 или новее.
Все команды выполняются из папки `app`.

```sh
npm ci
npm run dev
```

Интерфейс: http://127.0.0.1:5173. Сервер: http://127.0.0.1:3000.
Vite перенаправляет запросы `/api` на сервер. Проверка сервера: `/api/health`.

На странице выберите города и дату, введите цену и нажмите «Рассчитать».
Список маршрутов и доступные даты загружаются через `GET /api/routes`.
Для выбранного маршрута форма подставляет базовую цену. В результате
видны прогноз продаж, вместимость, загрузка и расчётная выручка. Под
результатом появляется график с девятью квантилями и отметкой вместимости.
Точные числа доступны по нажатию на «Все значения».

## Учётная запись

Нажмите «Войти», затем «Зарегистрироваться». Укажите email и пароль длиной
от 8 до 128 символов. После регистрации войдите с этим паролем. В шапке
появится email и кнопка «Выйти». Сессия действует до 7 дней.
Пароли хешируются scrypt с солью. Хеши старых аккаунтов обновляются
при успешном входе.

SQLite создаётся при запуске сервера в `storage/reshis.sqlite`.
Переменная `SQLITE_PATH` задаёт другой путь. При размещении используйте
постоянное хранилище и HTTPS. В режиме `NODE_ENV=production` cookie
получает флаг `Secure`.

## Серверный прогноз

После запуска запрос можно открыть в браузере или выполнить из терминала:

```sh
curl 'http://127.0.0.1:3000/api/forecast?route=MOW-AER&date=2026-06-01&price=10000'
```

Для этого рейса ответ содержит 900 мест, спрос 714 и прогноз продаж 714.
`quantiles` содержит девять пар `quantile` и `demand` для графика спроса.
Цена передаётся в рублях, дата в формате `ГГГГ-ММ-ДД`, маршрут кодом из `routes.csv`.
При высокой цене расчётный `demand` может быть отрицательным. `sales` всегда от 0
до вместимости включительно. Значения возвращаются без округления.

Неверные или пропущенные параметры дают `400`, отсутствующий рейс даёт `404`.

## Проверки и сборка

```sh
npm run check:data
npm run build
npm start
```

Сборка проверяет TypeScript и CSV, затем создаёт `client/dist` и `server/dist`.
После сборки Express отдаёт интерфейс и API с одного адреса http://localhost:3000.
Порт сервера можно изменить через переменную окружения `PORT`.

## Структура

- `client/src/App.tsx` — компоновка страницы и состояние результата.
- `client/src/components` — форма прогноза, результат, график и окно входа.
- `client/src/api` — запросы к прогнозу и учётной записи, типы ответов.
- `client/src/utils/format.ts` — форматирование дат и чисел.
- `client/src/assets` — SVG логотипа, импортируемый через Vite.
- `server/src` — Express, расчёт прогноза и хранение учётных записей.
- `data` — собственный ML-прогноз и справочник маршрутов.
- `scripts/check-data.ts` — проверка соответствия CSV условиям кейса.
- `storage` — локальное хранилище SQLite, исключено из Git.

## Данные и размещение

См. `data/README.md` для происхождения файлов и значения полей.
Сервер считает прогноз по формулам страниц 12–14 PDF.

Для размещения нужен хостинг с поддержкой Node.js и постоянным диском
для SQLite (либо подключение внешней базы). Файл базы должен сохраняться после
перезапуска и обновления приложения. CSV входят в проект и доступны только серверу.
Приложение опубликовано в ChatGPT Sites. [Открыть «Решись Авиа»](https://reshis-avia.auralartichoke4.chatgpt.site/).

Если Express доступен только через доверенные прокси, задай
`TRUST_PROXY_HOPS` равным их числу на пути запроса к серверу.
Например, для одного Caddy перед Express установи `TRUST_PROXY_HOPS=1`.
Для прямого запуска значение по умолчанию — `0`. Перед включением на
хостинге проверь, что запросы идут через указанное число прокси и
прямого публичного доступа к порту Express нет.
[Документация Express](https://expressjs.com/en/guide/behind-proxies/)
